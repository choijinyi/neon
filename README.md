# 설교 쇼츠 자동 생성기

설교 유튜브 링크를 입력하면 Gemini AI가 영상을 분석해서:

1. **하이라이트 구간 3개**를 자동으로 찾고
2. **설교 내용을 받아쓴 자막**을 입혀서
3. **세로(9:16) 쇼츠 미리보기**로 보여줍니다.

쇼츠 길이는 **30초 / 1분 / 3분** 중에서 선택할 수 있고,
**화면 녹화 방식으로 자막이 입혀진 세로 영상(MP4)** 을 바로 만들 수 있습니다.
(유튜브가 서버의 영상 다운로드를 차단하기 때문에, 브라우저에서 재생되는
쇼츠 미리보기를 그대로 녹화하는 방식을 씁니다 — 차단당하지 않고 항상 동작합니다.)
자막만 필요하면 SRT 파일로도 내려받아 프리미어·캡컷 등에서 쓸 수 있습니다.

## Vercel 배포

이 저장소를 Vercel에 연결하면 자동으로 배포됩니다.

- **환경변수**: 프로젝트 설정 → Environment Variables에 `GEMINI_API_KEY`를 추가해야
  하이라이트 분석이 동작합니다. (분석은 서버리스 함수 `api/analyze.ts`에서 실행되어
  키가 방문자에게 노출되지 않습니다)

## 로컬 실행

**필요한 것:** Node.js

1. 의존성 설치:
   `npm install`
2. `.env.local` 파일에 Gemini API 키 설정:
   `GEMINI_API_KEY=발급받은_키`
3. 앱 실행:
   `npm run dev`
